قیمت‌گذاری خودکار محصولات ووکامرس بر اساس نرخ ارز، طلا و فرمول‌های سفارشی.

== Description ==

افزونه طلا ارز پرو (Formula Price Sync) امکان به‌روزرسانی خودکار قیمت محصولات ووکامرس را بر اساس نرخ زنده طلا و ارز فراهم می‌کند.

ویژگی‌ها:

* فرمول استاندارد طلا مطابق قانون صنف طلا در ایران (مالیات فقط روی اجرت + سود)
* پشتیبانی از محصولات ساده و متغیر (Variable)
* دریافت نرخ از چندین منبع با Failover خودکار (TGJU → Navasan → Nobitex → Manual)
* Circuit Breaker برای جلوگیری از تغییرات ناگهانی قیمت (انحراف بیش از ۲۵٪)
* به‌روزرسانی دسته‌ای با Action Scheduler (چانک‌های ۵۰تایی)
* لاگ کامل تغییرات قیمت
* پاک‌سازی خودکار کش (WP Rocket, LiteSpeed, W3 Total Cache, ...)
* لایسنس سازگار با ژاکت و راستچین

== Installation ==

1. فایل ZIP را از طریق وردپرس آپلود و نصب کنید.
2. افزونه را فعال کنید.
3. کلید لایسنس را در منوی «طلا ارز پرو» وارد کنید.
4. در صفحه ویرایش محصول، گزینه‌های قیمت‌گذاری خودکار را تنظیم کنید.

== Frequently Asked Questions ==

= آیا مالیات روی ارزش خام طلا اعمال می‌شود؟ =
خیر. مطابق قانون جدید صنف طلا، مالیات فقط روی مجموع (اجرت + سود) محاسبه می‌شود.

= آیا از محصولات متغیر پشتیبانی می‌شود؟ =
بله. هر ورییشن می‌تواند تنظیمات مستقل داشته باشد.
